# BOTC Helper

Помощник игрока для игры **Blood on the Clocktower**: стол игроков, сценарии, роли и заметки — всё в браузере, без сервера.

## Возможности

- Стол в круге или квадрате с перестановкой мест (drag-and-drop)
- Раскладка 5–15 игроков с подсказкой T/O/M/D (+ странники)
- Встроенные сценарии (Trouble Brewing, Bad Moon Rising, Sects & Violets, Rival Cults, Chef's Deluxe) и загрузка своих сценариев с формате JSON
- Назначение ролей из сценария, метки «добро» / «зло», статус жив / мёртв
- Заметки по игроку и общие заметки партии
- Состояние сохраняется в `localStorage`

## Стек
React 19 · TypeScript · Vite

## Запуск

```bash
npm install
npm run dev
```

## Сборка
